# 1.引言

## 1.1编写目的
基于《sup-iam SAD》说明系统的总体架构设计，部署设计，明确各组件的配置设计,提供统一的配置实现参考
# 2. 全局配置优先级规范
根据配置参数所在位置，我们按如下由上到下的优先级覆盖

1. 硬编码显式设置
2. 命令行参数
3. 环境变量绑定
4. 配置文件手动配置
5. 配置文件默认值

# 3. 配置组成
考虑到各个组件的配置，特别是部署相关的配置存在重叠，因此在组件的配置项中必须明确如下两种配置

+ 应用配置
+ 部署配置

其中部署配置必须提供命令行配置和环境变量绑定的功能，方便容器化部署等部署方式进行配置导入
